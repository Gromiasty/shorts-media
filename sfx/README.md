# SFX Library

Efekty, tła i pętle muzyczne z ElevenLabs do Shortów „Once Upon a History”.
Przy nowym filmie najpierw bierzemy efekty stąd, a generujemy tylko brakujące i dopisujemy je tutaj (plik + wpis w `library.json`).

Bezpośredni link do pliku: `https://raw.githubusercontent.com/Gromiasty/shorts-media/main/sfx/<kategoria>/<nazwa>.mp3`
